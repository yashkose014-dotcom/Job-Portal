# 💼 Job Portal

A modern and responsive **Job Portal Web Application** that connects job seekers with employers. Users can explore job opportunities, search and filter listings, view job details, and apply for suitable positions through an easy-to-use interface.

## ✨ Features

### 👨‍💻 For Job Seekers

- 🔍 Search for jobs
- 📋 Browse available job listings
- 🏢 View company information
- 📄 View detailed job descriptions
- 📍 Search jobs by location
- 💼 Filter jobs by category
- 💰 View salary information
- 📝 Apply for jobs
- ❤️ Save/bookmark jobs
- 👤 Manage user profile

### 🏢 For Employers

- ➕ Post new job openings
- ✏️ Edit job listings
- 🗑️ Delete job listings
- 👥 View applicants
- 📊 Manage posted jobs
- 🏢 Manage company profile

### 📱 General Features

- 🔐 User authentication
- 📱 Fully responsive design
- 🎨 Modern and clean UI
- ⚡ Fast performance
- 🔎 Job search and filtering
- 🌙 Responsive/mobile-friendly interface

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/job-portal.git
```

### 2. Navigate to the project directory

```bash
cd job-portal
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

```text
http://localhost:5173
```

---

## 📦 Build for Production

Create a production-ready build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
